# RaceTrace
final year project

## Backend Project
### Requirements
- [Python](https://www.python.org/) 3.10 or later
- [Pip](https://pypi.org/project/pip/)
- [Git](https://git-scm.com/)
### Setup
- Clone the repo
- Create a Python virtual environment in the base repository and activate it
- run commands:
    - `cd backend`
    - `pip install -r requirements.txt`
    - `python manage.py runserver`
- in your browser, open localhost:8000/
## Frontend (optional)
- ensure [Node.js](https://nodejs.org/en) and [npm](https://www.npmjs.com/) are installed
- after running the python server, open a new terminal in `frontend/racetrace-app`
- run commands:
    - `npm install`
    - `npm run dev`
- in your browser, open localhost:5173/
